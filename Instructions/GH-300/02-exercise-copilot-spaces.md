# Democratize tribal knowledge using Copilot Spaces

In this lab, you will learn how to use GitHub Copilot Spaces to capture, share, and democratize tribal knowledge across your organization. Copilot Spaces helps teams preserve institutional knowledge and make it accessible to all team members, reducing dependency on individual experts.

You will learn how to:

- Understand what Copilot Spaces is and its benefits
- Create and configure Copilot Spaces
- Capture tribal knowledge effectively
- Share knowledge with your team
- Use AI to make knowledge more accessible
- Integrate Spaces into your workflow

This lab takes approximately **30-45** minutes to complete.

## Before you start

To complete the lab, you need:

- A GitHub user account with access to GitHub Copilot.
- Basic understanding of collaboration tools.
- A web browser with access to the internet.

## Complete the exercise on Microsoft Learn

In this exercise, you'll learn about Copilot Spaces through a hands-on exercise.

> **Note:** This exercise guides you through using Copilot Spaces to democratize knowledge and improve team collaboration.

The exercise consists of the following activities:

1. Start a web browser and navigate to the exercise page: [https://learn.microsoft.com/en-us/training/modules/introduction-copilot-spaces/4-skills-exercise](https://learn.microsoft.com/en-us/training/modules/introduction-copilot-spaces/4-skills-exercise)

1. Follow the instructions provided in the exercise to complete all challenges.

1. Work through each step, learning how to effectively capture and share knowledge using Copilot Spaces.

1. When you finish, return to the module for a knowledge check and completion badge.

## What you've learned

After completing this exercise, you should be able to:

- Understand Copilot Spaces functionality
- Capture and organize tribal knowledge
- Share knowledge effectively with teams
- Use AI to make knowledge more accessible
- Integrate knowledge sharing into daily workflows

Congratulations! You've completed the Copilot Spaces exercise!
