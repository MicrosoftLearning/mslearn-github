# Expand your team with Copilot coding agent

In this lab, you will learn how to use GitHub Copilot's coding agent capabilities to enhance your team's productivity. The coding agent goes beyond simple code completion to help with complex tasks like refactoring, debugging, and implementing features across multiple files.

You will learn how to:

- Understand Copilot coding agent capabilities
- Use the agent for complex development tasks
- Collaborate with the AI agent effectively
- Leverage agent for multi-file changes
- Apply agent suggestions to real projects
- Integrate the coding agent into team workflows

This lab takes approximately **45-60** minutes to complete.

## Before you start

To complete the lab, you need:

- A GitHub user account with access to GitHub Copilot.
- Experience with software development.
- Understanding of version control with Git.
- A web browser with access to the internet.

## Complete the exercise on GitHub

In this exercise, you'll learn to work with the Copilot coding agent.

> **Note:** This exercise demonstrates how to leverage AI agents for complex development tasks.

The exercise consists of the following activities:

1. Start a web browser and navigate to the exercise page: [https://github.com/skills/expand-your-team-with-copilot/](https://github.com/skills/expand-your-team-with-copilot/)

1. Follow the instructions provided in the exercise to complete all challenges.

1. Work through each step, using the Copilot coding agent for complex development tasks.

1. When you finish, return to the module for a knowledge check and completion badge.

## What you've learned

After completing this exercise, you should be able to:

- Understand coding agent capabilities
- Use agents for complex tasks
- Collaborate effectively with AI agents
- Apply agent suggestions to projects
- Integrate agents into workflows
- Enhance team productivity with AI

Congratulations! You've completed the coding agent exercise!
